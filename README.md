## 几个常被问到的细节

**欧洲机房到国内延迟怎么样？**

荷兰阿姆斯特丹到国内的物理距离决定了延迟不可能像日本、香港那么低，正常情况下电信方向 200ms 左右，联通和移动视线路而定。CN2 GIA 回程的优势不在延迟而在晚高峰的丢包和抖动控制，普通商业线路在晚高峰经常会明显掉速。

**EUNL_3 是不是下线了？**

部分中文站显示 EUNL_3 已经逐步被 EUNL_2 替代，新购时可选机房以官网 KiwiVM 面板的实时列表为准。已购套餐如果原来挂在 EUNL_3，迁移时可以选 EUNL_2 或其他可用机房。

**限量版套餐能不能续费？**

可以，限量版套餐续费价格和首发价格一致，优惠码同样适用。问题不在续费，而在**新购**——限量版常年缺货，能买到主要靠补货时机。

**搬瓦工支持 Windows 吗？**

常规 KVM 套餐 4GB 内存以上支持 Windows 系统（需额外授权费），CN2 GIA-E 系列同样支持。1GB 内存的低档套餐不建议装 Windows，实际体验会很差。

**和 Vultr、RackNerd 的欧洲 VPS 比怎么选？**

如果你的主要访问端在国内，搬瓦工的 CN2 GIA 线路优势明显；如果访问端主要在欧美本地，Vultr 这类按小时计费的海外大厂更灵活，RackNerd 价格更低但线路没有国内优化。选哪个取决于你的流量来源，不是单纯比价格。
